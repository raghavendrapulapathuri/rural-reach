# Rural Reach 🌾

Rural Reach is a comprehensive web platform designed to bridge the digital divide and empower rural communities in India by providing easy access to government schemes, agricultural tools, and educational resources.

## 🎯 Purpose

The platform serves as a one-stop solution for rural communities to:
- Access information about government schemes and benefits
- Learn about modern agricultural tools and techniques
- Engage with educational content
- Connect with the larger rural community

## ✨ Features

### 1. Government Schemes 📜
- Detailed information about various agricultural and rural development schemes
- Easy-to-understand eligibility criteria
- Step-by-step application procedures
- Direct links to official portals

Key schemes covered:
- PM Kisan Samman Nidhi
- Kisan Credit Card (KCC)
- Pradhan Mantri Fasal Bima Yojana (PMFBY)
- Soil Health Card Scheme
- Pradhan Mantri Krishi Sinchayee Yojana (PMKSY)
- National Agriculture Market (eNAM)
- Rashtriya Krishi Vikas Yojana (RKVY-RAFTAAR)

### 2. Agricultural Tools & Technology 🚜
Information about modern farming tools and technologies:
- Drip Irrigation Systems
- Solar Water Pumps
- Polyhouse Farming
- Crop Harvesting Machines
- Precision Farming Technology
- Vertical Farming Setups
- Agricultural Drones

### 3. Learning Resources 📚
- Educational content about farming practices
- Video tutorials
- Best practices documentation
- Sustainable agriculture guides

### 4. Community Features 👥
- Discussion forums
- Experience sharing
- Local market updates
- Weather information

## 🛠️ Technical Stack

- Frontend: React.js with TypeScript
- Styling: Tailwind CSS
- State Management: React Context
- AI Integration: Google Gemini API
- Authentication: Firebase Auth

## 🚀 Getting Started

1. Clone the repository:
\`\`\`bash
git clone https://github.com/raghavendrapulapathuri/rural-reach.git
\`\`\`

2. Install dependencies:
\`\`\`bash
npm install
\`\`\`

3. Start the development server:
\`\`\`bash
npm run dev
\`\`\`

## 🌐 Environment Setup

Create a \`.env\` file in the root directory with the following variables:
\`\`\`env
VITE_GEMINI_API_KEY=your_gemini_api_key
VITE_FIREBASE_CONFIG=your_firebase_config
\`\`\`
